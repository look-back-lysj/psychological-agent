## 四、额度规划（对应「实验室额度有限」）

| 做法 | 说明 |
| --- | --- |
| **不传 `max_tokens` 虚高** | 官方口径：计费按 `max_tokens` 与输入估算的**较大者**，虚高会提前触发限流 |
| **含图轮次单独抬预算** | 视觉任务思考 token 实测占 151—463，默认 512 会得到空回复 → 含图轮抬到 ≥1024（仅含图轮） |
| **连通性自检走 `GET /models`** | **零 token 成本**（改前是发一次 chat 请求） |
| **Open 寒暄/短消息跳过「观」** | `decideTier()` 对 L0 短消息与重复消息走 minimal 档，省一次调用 |
| **「校」只在本地规则命中时调用** | 实测触发率 A 5% / B 2.5%（40 轮各 2/1 次） |
| **L3 危机走固定话术** | **0 次模型调用**（本轮 A/B 各 2 轮危机协议，均未调模型） |
| **重试只对 408/409/429/≥500** | 401/402 等立即失败，不浪费额度 |
| **静态加密不增加 token** | 会话与记忆加密只影响落盘表示，与调用成本无关 |
