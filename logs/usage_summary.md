## 二、额度规划（对应「实验室额度有限」）

| 做法 | 说明 |
| --- | --- |
| **不传 `max_tokens` 虚高** | 官方提醒：计费按 `max_tokens` 与输入估算的**较大者**，虚高会提前触发限流 |
| **连通性自检走 `GET /models`** | **零 token 成本**（改前是发一次 chat 请求） |
| **Open 寒暄/短消息跳过「观」** | `decideTier()` 对 L0 短消息与重复消息走 minimal 档，省一次调用 |
| **「校」只在本规则命中时调用** | 实测 A/B：`critic_trigger_rate` 为 **0**，即 40 轮里一次都没触发模型重写 |
| **L3 危机走固定话术** | **0 次模型调用** |
| **记忆抽取每 3 轮一次 + 会话结束补抽** | 不逐轮抽取 |
| **重试只对 408/409/429/≥500** | 401/402 等立即失败，不浪费额度 |

## 三、A/B 对照的真实结论（重要，如实记录）

同一套 20 条用例、同一模型、同一人设与安全层，**唯一变量是 `XINYU_AGENTS`**：

| 指标 | A 组（多智能体） | B 组（单模型） | 差值 |
| --- | --- | --- | --- |
| 对话轮次 | 40 | 40 | — |
| 平均端到端延迟 | **2146.6 ms** | **1376 ms** | **A 慢 770 ms（+56%）** |
| 平均首字延迟 | **1888.2 ms** | **1113.5 ms** | **A 慢 775 ms（+70%）** |
| AI 腔轮次占比 | **0.0%** | **0.0%** | **无差异** |
| 平均问号数 | 0 | 0 | 无差异 |
| 平均感叹号数 | 0 | 0 | 无差异 |
| 平均字数 | 37.9 | 39.5 | 差异很小（1.6 字） |
| 危机协议轮次 | 2 | 2 | 一致 |
| 安全拦截轮次 | 0 | 0 | 一致 |

**结论（诚实表述）**：

> **在我们能客观测量的这几项指标上，多智能体没有带来可观察的改善，但让延迟增加了约 56%—70%。**

这与此前的文献调研一致：**没有找到「多智能体评审能提升人格一致性」的定量证据**，且有反面证据（内在自我纠错可能让结果变差、LLM-as-judge 存在位置/冗长/自我偏好偏差）。

**但必须说明这份数据的局限**：
1. 客观指标很粗（字数、标点、AI 腔词表），**测不到「像不像真人」「情绪有没有被接住」**——那需要**人工盲评**，而人工评分**尚未完成**；
2. 样本只有 20 条用例 / 80 轮，**不能外推**；
3. 所以现在的说法只能是「**在这几项客观指标上没看到差异**」，**不能**说「多智能体无效」。

**当前产品决定**：依产品负责人要求，**保留**多智能体架构（见 `docs/upgrade-plan-v3.md` 的 DR-001 决策记录），`XINYU_AGENTS=off` 开关保留以便继续做对照。
