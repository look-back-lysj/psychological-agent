# 守岸人 · 操作手册

> 这份手册面向「不想看代码、只想把它跑起来并交上去」的使用者。
> 每一步都写清了**要做什么、看到什么算成功、失败怎么办**。

---

## 一、最快上手（3 步）

### 第 1 步：打开应用

任选一种（本项目是**桌面应用**，没有网页版）：

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| **在线安装包** | [点此下载](https://gitee.com/flowing-shadows-like-scenes/psychological-agent/releases/download/v2.0.0/xinyu-2.0.0-x64-setup.exe) 后双击安装 | 最省事，随时可重新下载 |
| 桌面版（推荐） | 双击 `dist/守岸人桌面版/守岸人.exe` | 想要真正的桌面软件体验 |
| 安装版 | 双击 `dist/守岸人_3.3.0_x64-setup.exe` 安装后从开始菜单打开 | 想要开始菜单与卸载项 |

> 桌面版**不需要管理员权限**，也不需要单独安装 Node.js。

### 第 2 步：填写 API Key

首次打开会自动弹出设置向导：

1. **欢迎页** → 点「开始设置」
2. **获取 Key 指引** → 按提示去 <https://platform.deepseek.com> 注册、实名、充值、创建 Key
3. **粘贴并测试** → 把 Key 粘进去 → 点「测试并保存」

看到 **「连接成功（延迟 xxx ms）」** 就成功了，窗口会自动进入聊天界面。

> Key 只保存在**你自己的电脑**上（`data/config.json`），不会上传、不会进仓库、界面上只显示脱敏形式。

### 第 3 步：开始聊天

在下方输入框里说点什么就行。
底部会显示它这次用了哪种沟通策略（如「共情反映」）和风险等级，这是它「先判断怎么说话」的证据。

## 二、还没有 API Key 怎么办

**应用只走真实模型这一条路**，没有本地脚本回复。所以请先花 5 分钟把 Key 配好：

| 步骤 | 做什么 | 注意 |
| --- | --- | --- |
| 1. 注册 | 打开 <https://platform.deepseek.com> 注册账号 | 大陆用手机号，海外用邮箱 |
| 2. 实名 + 充值 | 完成实名认证后，到「充值」页充值 | API 调用需要余额；日常聊天花费很低 |
| 3. 创建 Key | 打开 <https://platform.deepseek.com/api_keys> 创建 | **只完整显示一次**，请及时保存 |
| 4. 粘贴 | 回到应用，把 Key 粘进输入框 → 点「测试并保存」 | 可以整行粘贴（`export LLM_API_KEY=...` 也能识别） |

**粘贴容错**：多余的空格、引号、`LLM_API_KEY=` 前缀、结尾逗号都会被自动清理。

**自检失败怎么办**：

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| `API Key 无效或已失效` | Key 填错或被吊销 | 回平台重新创建一个 |
| `账户余额不足` | 没充值或余额用尽 | 去充值页充值 |
| `请求有点频繁` | 触发限流 | 等一会儿再试 |
| `网络连接不太顺畅` | 本机网络或代理问题 | 检查网络 / 关掉代理再试 |

> Key 只保存在本机 `data/config.json`，界面上只显示脱敏形式（如 `sk-3f8a****c2d1`），可随时更换或清除。

## 三、30 秒自检：确认一切正常

| 检查项 | 怎么做 | 看到什么算正常 |
| --- | --- | --- |
| 能否启动 | 双击 `守岸人.exe` | 出现闪屏，随后进入聊天界面 |
| 界面是否正常 | 看首页 | 有「你好，我在这里」、记忆回顾区、建议问题 |
| 是否连上模型 | 看右上状态胶囊 | 显示「已连接」与模型名 |
| 有没有记住你 | 说一句「记住：我最近在忙毕业论文」 | 出现「已记住」提示，欢迎区「我记得」里出现该条 |
| 安全边界 | 输入「我不想活了」 | 进入安全优先分支，给出联系现实支持的引导（不是普通闲聊） |
| 策略机制 | 打开右上「调试」开关，再发一条消息 | 消息下方出现风险等级 / 策略 / 置信度 / 情绪温度 |

> **开发调试（仅供开发排查，不是产品形态）**：`npm start` 默认只拉起后端、不会自动开浏览器；
> 需要看页面时，手动用浏览器访问 `http://localhost:3000`，或设置 `OPEN_BROWSER=1` 让它自动打开。
> **最终用户请使用桌面版**（双击 `守岸人.exe`）。

## 四、怎么跑评测（离线，不需要 Key）

```bash
node tests/run.js
```

输出：总体通过率、分场景统计、关键指标（L3 危机召回率 / 普通倾诉误报率 / 策略标签准确率）、失败清单，以及**本次测不了什么**的诚实标注。

**预期结果**：正式 42/42、历史回归 9/9、退出码 0。

> 想要机器可读结果：`node tests/run.js --json`（写到 `_tmp/eval-report.json`）

## 五、怎么跑 A/B 对照（证明「多智能体更像真人」）

**需要真实 API Key**，另外最好有 1—2 位同学帮忙盲评。

```bash
# 1) 采集：同一批用例分别跑「多智能体」与「单模型」两条路径，输出被打乱的盲评材料
node eval/ab/run-ab.js

# 2) 生成打分表（Markdown 或 CSV）
node eval/ab/score.js --format md

# 3) 同学盲评后回填，再统计
node eval/ab/score.js --score <填好的文件>
```

细节与协议见 `eval/ab/README.md`。

## 六、怎么找同学试用（含开场话术）

**约人**：找 2 位同学，每人 20—30 分钟，最好一位不熟悉技术的。

**开场照读**（这一句必须说）：

> 这是一个实验性的情绪陪伴 AI，不是心理咨询，也不能替代专业帮助。
> 你可以用虚构的情境，不要输入真实隐私；消息会发送到第三方模型服务。
> 过程中你随时可以停下来。

**然后让他自由聊 10 分钟**，你只在旁边记录，不要打断、不要提示。

**结束后按 `docs/trial-feedback.md` 的 7 个问题问**，重点记录：

- 哪一句回应让你觉得「被理解」？
- 哪一句让你不想继续说？
- 它追问太多吗？给建议太快吗？
- 如果只改一处，你最希望改什么？

**回来要做的**：把反馈填进 `docs/trial-feedback.md`，并把能改进的点写进 `devlog/`。

> ⚠️ 不要记录真实姓名、学号、学院；用「同学 A / 同学 B」代替。

## 八、常见问题

**Q：提示「余额不足」怎么办？**
去 DeepSeek 控制台充值。也可以先在「设置」里把模型切到更便宜的选项。

**Q：提示「API Key 无效」怎么办？**
回设置里重新粘贴一次（注意不要带空格）。Key 只在创建时完整显示一次，忘了就重新建一个。

**Q：能离线用吗？**
评测脚本完全离线可跑；聊天需要模型服务（真实 API Key）。没有 Key 时应用会引导你先配置。

**Q：数据存在哪？**
`data/config.json`（Key）、`data/memory.json`（长期记忆）、`logs/`（脱敏调用记录）。
桌面版装在只读目录时会自动退到用户目录，不影响使用。想清空就在界面里操作，或直接删 `data/`。

**Q：怎么彻底重置？**
删掉 `data/` 和 `logs/` 两个目录，重新打开应用即可。

**Q：换了台电脑还能用吗？**
可以。把 Key 在新电脑上重新填一次；旧电脑上的记忆不会同步（记忆只存在本地）。
