## 三、每日固定动作（可照做）

```bash
node tests/run.js          # 跑评测，确认没有回退
git add -A && git commit -m "..."   # 一天一次提交
```

把当天的进展写进 `devlog/dayNN.md`（目标 / 完成内容 / 验收 / 待办 四段）。

## 四、风险与降级预案

| 风险 | 预案 |
| --- | --- |
| API 额度不足 | 关闭思考模式、显式 `max_tokens`、保持 system prompt 前缀稳定以命中缓存；评测用例可分批跑 |
| 没有 API Key 时演示 | 内置**免 Key 演示模式**，可完整感受交互；评测的 L1 层完全离线可跑 |
| 同学临时退出 | 提前约 3 位，最终记录 2 位 |
| 评测结果不理想 | 如实报告 + 原因分析 + 迭代后重测；「发现无效」也是有效结论 |
| 指定场景口径不符 | 系统与场景文案解耦，改文案不改架构 |
