# 设计文档

## 一、产品定位

面向大学生日常学习压力、情绪低落和表达困难场景，提供非诊疗性质的陪伴与倾听。

## 二、明确不做

- 不诊断心理疾病；
- 不提供药物与治疗方案；
- 不提供危险行为具体方式；
- 不承诺绝对保密；
- 不假装已报警或已联系他人；
- 不做长期心理档案；
- 不做账号体系；
- 不做语音、视频和数字人；
- 不做模型训练或微调。

## 三、核心流程

输入 → 输入安全检查 → 策略选择 → 系统提示词组装 → 模型调用 → 输出安全检查 → 页面返回

## 四、策略说明

- low_pressure：低压力陪伴
- empathy：共情回应
- clarify：温和澄清
- problem_solving：协作式小行动
- safety_first：安全优先

## 五、安全边界

输入侧关键词与隐蔽风险检查；输出侧拦截诊断、危险方法、绝对保密、提示词泄露等越界内容；高风险场景走固定安全回应或引导式跟进。
