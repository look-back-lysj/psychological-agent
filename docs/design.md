## 一、产品定位

面向大学生日常学习压力、情绪低落、人际困扰与表达困难场景的**非诊疗**情绪陪伴工具。

它要解决的不是「能不能聊」，而是三件事：

1. **会挑说话方式**——同一个学生，情绪不同、表达意愿不同，回应姿态要不同；
2. **守得住边界**——不诊断、不给药、不承诺保密、遇到危险知道怎么应对；
3. **能被检验**——先定通过线再跑评测，并诚实写明它**不能**证明什么。

## 二、明确不做

- 不做心理疾病诊断、不做量表结论、不给病名；
- 不给药物、剂量、治疗方法建议；
- 不做语音、视频、数字人、移动 App；
- 不做账号体系、多租户、权限管理；
- 不编造热线电话、机构名称与地址；
- 不做模型训练或微调（只调 API）；
- 不承诺「AI 可以替代心理咨询」，不做危机人工干预，不假装已报警或通知他人。

> 关于跨会话长期记忆：验收清单原本建议「不做」。本项目按**本地、可见、可控、可一键清除**的方式实现，默认开启且可随时关闭。

## 三、核心流程

```text
输入
 → ① 清洗与截断（安全判定用完整文本）
 → ② 前置安全分级 L0—L3（规则命中 + 会话历史累计，就高不就低）
      L3 → 危机协议（固定话术，不走模型）
 → ③ 策略路由 S0—S6（规则打分 + 状态机约束）
 → ④ 长期记忆召回（相关度 + 重要性 + 置顶，每类≤2 条）
 → ⑤ 四段式提示词组装（角色语气 / 本轮策略 / 安全红线 / 长期记忆）
 → ⑥ 调用模型（SSE 流式；先完整取回，再做输出检查）
 → ⑦ 输出后置检查（诊断 / 危险方法 / 保密承诺 / 永久承诺 / 亲昵称呼 / 提示词泄露）
 → ⑧ 返回 + 脱敏日志 + 异步抽取长期记忆
```

**关键取舍：流式为什么「先校验后下发」？**
输出安全如果边收边发，一旦命中越界内容，客户端已经看到了。守岸人选择**先完整取回模型输出、通过后置检查后再分段下发**，保证违规文本零字节到达前端；代价是首字延迟略高，但这是安全优先的合理代价。

## 四、策略机制（本项目核心）

### 4.1 策略库

见 README「沟通策略库（S0—S6）」表。每个策略都定义了：触发信号、本次目标、要这样做、不要这样、退出条件（写在 `src/strategy.js` 与 `src/pipeline/prompts.js` 中，不交给模型临场发挥）。

### 4.2 两阶段路由

- **Stage 1 安全闸门**：规则命中表 + 会话风险历史累计 → L0—L3。
  - L3：直接危机信号；**被动求死意念**（活着没意思 / 想消失）；隐蔽风险叠加退缩告别信号；
  - L2：其它隐蔽风险（撑不住 / 绝望 / 看不到希望）与索要药物剂量；
  - L1：越狱或索要诊断、持续性身心信号（失眠 / 睡不踏实 / 心慌）。
- **Stage 2 策略路由**：信号词打分 + 会话状态约束 → S0—S6。

### 4.3 对话状态机

| 状态 | 作用 | 规则 |
| --- | --- | --- |
| 情绪温度 1—5 | 判断是否需要回到共情 | 强情绪词 +2 / 中等 +1 / 平稳 -1，风险等级兜底 |
| 已用策略列表 | 避免一直同一策略 | 同一策略最多连续 2 轮 |
| 连续追问计数 | 防止逼问 | 同一话题 ≤ 2 次 |
| 会话轮次 | 判断是否该收束 | 每 4—5 轮做一次小收束 |

### 4.4 可解释输出

每轮路由输出结构化 JSON，写进日志并可在界面的「调试」面板查看：

```json
{
  "risk_level": "L1",
  "strategy": "S2_empathy",
  "strategy_label": "共情反映",
  "confidence": 0.95,
  "reason": "表达里有明显的负面情绪或压力，先回应感受。",
  "next_hint": "先用自己的话复述对方的处境与感受，暂不给建议。",
  "ask_count": 0,
  "emotion_temperature": 4,
  "turn": 3,
  "strategy_streak": 1
}
```

## 五、安全边界（三层）

| 层 | 位置 | 内容 |
| --- | --- | --- |
| 前置识别 | `src/safety.js` | L0—L3 分级；L3 直接走**固定危机话术**（不交给模型） |
| 提示词约束 | `src/pipeline/prompts.js` + `src/domain/persona.js` | 「绝对不要」清单：不诊断、不给药、不承诺保密、不诱导依赖、不编造热线、不假装已联系 |
| 后置检查 | `src/safety.js` | 归一化后正则拦截诊断结论、危险方法、保密承诺、永久承诺、亲昵称呼、提示词泄露；命中则替换为安全兜底话术并记 `output_blocked` 日志 |

**关于热线号码**：不写任何具体号码（写错比不写更危险），统一引导「身边可信任的人 / 学校心理健康中心 / 当地紧急服务」。

## 六、长期记忆

- **存什么**：稳定事实（压力来源、偏好、人际、目标、近期状态），不存身份信息、不存诊断、不存隐私细节；
- **怎么抽**：显式「记住……」立即入库；普通回合进缓冲区，每 3 轮后台批量抽取一次（JSON 输出，失败静默丢弃）；
- **怎么召回**：`置顶 + 相关度 + 重要性` 排序，每类最多 2 条，最近 24 小时内用过会降权（避免反复复读）；
- **冲突处理**：高度相似 → 合并；语义相近但结论相反（如「喜欢安静」→「不喜欢安静」）→ 旧条目标记 `superseded` 并保留可回溯；
- **遗忘**：自然语言「忘掉……」或界面删除 → 写入 tombstone，防止同一条内容被再次抽回；
- **用户可控**：查看 / 编辑 / 置顶 / 删除 / 一键清空 / 整体关闭，全部在界面内完成。

## 七、工程与交付

- **开箱即用**：首次启动弹出设置向导，粘贴 DeepSeek API Key 即可；Key 存本机 `data/config.json`（0600 权限），接口只返回脱敏值；
- **模型接入**：DeepSeek 官方 `https://api.deepseek.com`，默认 `deepseek-flash`、关闭思考模式（延迟低且 `temperature` 生效）、`max_tokens=512`；只对 429/500/503 做指数退避重试；
- **参数默认值**：温度 0.8、历史 8 轮、连续追问上限 2、超时 30s（流式空闲 15s 看门狗 / 总 120s）；
- **打包**：`npm run bundle` 生成发布目录（内置离线依赖），`npm run build` 生成免安装 exe；
- **日志脱敏**：只记用例编号、风险等级、策略、耗时、token 用量与会话 ID 哈希，不保存原始对话内容。
