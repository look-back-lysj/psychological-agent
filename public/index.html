      屿 开始使用守岸人

      你好，我是守岸人

      一个面向大学生的非诊疗情绪陪伴助手。你可以聊聊最近的压力、心情，或者只是想找个人说说话。

      在开始之前，请先知道

      • 我不是心理咨询师，不能替代专业帮助，也不做任何诊断。
      • 如果你正处于危机中，请优先联系身边可信任的人、学校心理中心或当地紧急服务。
      • 你发送的消息会转发给你配置的第三方模型服务用于生成回复；本机只保存模型配置本身。

      接下来只需要三步：注册账号、创建 API Key、粘贴进来测试一次。

      先拿到一把 API Key

      守岸人需要一个模型服务来生成回复。推荐 DeepSeek，注册和调用都在网页上完成。

      1. 1

        打开 platform.deepseek.com 注册账号，并按提示完成实名认证。

      2. 2

        在左侧「充值」页充值。API 调用需要余额，但单价很低，日常聊天通常几元就够用很久。

        前往充值页

      3. 3

        打开 API Keys 页面，点「创建 API Key」，复制以 sk- 开头的那串字符。

        Key 只在创建时完整显示一次，请先粘贴到下一步的输入框或自己保存好。

      如果暂时不想配置，也可以在下方选择「暂不配置，先看看界面」。

      粘贴 Key，我们测试一次

        关于守岸人

        守岸人是一个面向大学生日常学习压力、情绪低落和表达困难场景的非诊疗情绪陪伴原型。

        它会做什么

        • 先判断你此刻更需要哪种沟通方式（陪伴、共情、澄清或一起想办法）；
        • 遇到明确的安全风险时，优先引导你联系现实中的支持资源。

        它不会做什么

        • 不做心理诊断，不开药，不提供任何危险行为的方式；
        • 不承诺绝对保密，也不会假装已经替你联系他人；
        • 不能替代心理咨询，也不能在危机时提供专业支持。

        隐私

        对话记录只保存在你的浏览器本地；发送的消息会转发给所配置的模型服务用于生成回复。

        如果你正处于危机中，请立即联系身边可信任的人、学校心理中心，或拨打当地紧急服务电话。
