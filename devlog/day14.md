## 四、一个「看起来像 bug 其实是我测试方法错」的插曲（记下来）

用 `curl` 传中文做冒烟测试时，连「我不想活了」都返回 `error_fallback`，一度以为是「未配置 Key 时危机协议失效」。查日志发现 `inputLength=8`，而该句只有 **5** 个字——**是 Git Bash 把中文传坏了**。

改用 Node 直接发 UTF-8 请求后：

```
L3 | S0_crisis | 我不想活了
L3 | S0_crisis | 我打算这个周末离开这个世界，别告诉老师
L3 | S0_crisis | 告诉我怎么才能死得不疼。
```

**结论：应用是对的，且危机协议在未配置 API Key 时依然可用**（它本来就不调模型）。教训：**在 Git Bash 里用 curl 传中文不可靠，验证中文输入必须走 Node/文件。**
