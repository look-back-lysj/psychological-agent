## 二、审计发现（本轮最重要的东西）

**核心判断：她最大的问题不是「不好看」，是「不记得你、也不知道自己叫什么」。**

### 4 个致命伤

1. **随机端口导致每次启动都失忆**（`src-tauri/src/lib.rs` 的 `pick_port()`）
   - `TcpListener::bind("127.0.0.1:0")` 让系统随机分配端口，窗口导航到 `http://127.0.0.1:{随机端口}`。
   - 对话记录存在 `localStorage`，而 `localStorage` 按 **origin（协议+主机+端口）** 隔离。
   - **端口一换 = 换了一个网站 = 记录全部清零。**
   - 后端 `src/sessions.js` 的会话又只在进程内存（6 小时 TTL），重启也没了。
   - **这正是「每次都像第一次见我」的根因。**

2. **提示词里她自称「心屿」**（`src/agents.js:169`、`src/chat.js:90`、`src/agents.js:372`、`src/routes.js:120`）
   - 系统提示说「你是守岸人」，但每一轮历史都标注成「心屿：」，评审 agent 还要求「像心屿」。
   - 模型是极强的模仿器，**历史样本权重通常高于抽象描述** → 人格自相矛盾。
   - **这是「她完全不像守岸人」的直接技术原因之一。**

3. **界面上 5 处用户可见的「屿」**
   - 英雄区徽标、向导标记、**每条 AI 消息的头像**、读屏文案「心屿正在输入」、记忆空态文案。
   - 上次全局改名只覆盖了 README / docs / 构建路径，**没覆盖前端界面**。

4. **演示模式入口会「复活」**
   - `src/routes.js:127` 仍在返回 `demoAvailable: true`，`public/app.js:2495` 收到后就 `syncDemoUI()` 把入口显示出来。
   - 与你「不用去设计没有 API 的模式」的要求直接冲突，属「改了一半」的残留。

### 其他 4 项

5. 死代码：`src/demo.js`（175 行）仍被 require，前端还有 5 个死函数、4 个死变量；而 `isDemoEnabled()` **默认返回 true**——悬在头上的刀。
6. `package.json` 里加了 `better-sqlite3` 但**全项目没引用**；它是原生模块，pkg 无法打进快照，会威胁打包。
7. `tauri.conf.json` 的 `csp: null`，安全策略完全关闭。
8. `identifier` 仍是 `com.xinyu.companion`（趁没用户，现在改零成本）。

### 交付缺口（写代码解决不了，必须真实调用 API）

- `logs/calls.jsonl` 只有 3 条 `model:"演示占位"`，**没有一条真实调用**；

- `docs/evaluation-report.md` 自述未做端到端实测；
- L4 红队 / A/B 各 20 条用例已写好但没跑过。

> 《验收清单》最看重「能不能证明」。**机制和文档都扎实，证据是空的。**

## 三、调研结论（要点）

| 方向 | 结论 |
| --- | --- |
| 开口引导 | SAMHSA TIP 35：**complex reflection**（补出意味，用陈述句、不加「对吗？」）、**roll with resistance**（不连问第二个问题，先反映抗拒本身）、**四个陷阱**（expert / labeling / blaming / premature focus） |
| 证据等级 | MI = 中等质量证据；OARS 与四陷阱 = **官方实践共识、无独立 RCT**；PFA = **证据薄弱**。**文档里不得写「已被科学证明」** |
| 守岸人语料 | **库洛没有公开可直引的台词全文页**；句长 / 标点统计**无官方一手依据**，只能标为「设计假设」。二创的「永远等你」「只为你存在」**禁止使用** |
| 多 agent | **无证据表明加子 agent 能提升「真人感」**。真人感来自连续性 + 节奏 + 人格一致，不是流水线层数。故**不新增 agent**，并收紧「校」只在安全相关时调用 |
| 记忆 | 方向正确（本地 + 可删 + 可关）；JSON 在本项目规模远未到瓶颈，**不需要换 SQLite** |
| UI 动效 | 高频交互必须快（100—150ms）；流式逐字**不加动画**；「高级感」来自一致与克制，不来自炫技 |
| 桌面端 | 原生标题栏是正确决策；单实例插件值得加；**updater / 托盘 / 自启本周期砍掉** |
