# 开发日志 - 第 7 天

## 目标

复查规划与设计，补齐「让人愿意继续交互」的体验短板，并把无法自动完成的实验做成交付物。

## 一、复查发现的三个真短板

1. **没有情感连续性**：每次打开都是同一句「你好，我在这里」，四条约会建议是写死的——用户感受不到「它记得我」，而这正是陪伴类产品的粘性来源。
2. **没有 Key 时体验是断的**：无法感受完整交互，演示与验收都会卡住。
3. **视觉是「干净的 SaaS 风」，还不是「高级」**：缺氛围层、材质层次与动效编排。

## 三、回来体验（情感连续性）

- `GET /api/comeback` **零模型调用**，瞬时返回：问候语、记住的事、动态建议；
- 15+ 条问候模板，按「首次 / 时段 / 间隔长短 / 有无记忆」组合：
  - 深夜：`这么晚还醒着。先说说你现在是什么状态就好。`
  - 有记忆：`又见面了。上次你提到「毕业论文」，今天还好吗？`
  - 久未见面：`有一阵子没见了。不用解释什么，想从哪儿说起都可以。`
- 建议问题**从长期记忆里生成**（如记忆是「毕业论文焦虑」→「还是论文的事 / 今天状态还行 / 想说点别的」），不再是写死的四条；
- 实测效果：晚上打开时标题显示 **「晚上了。」**，副标题「要是今天没能顾上自己，现在可以慢一点。」

## 四、免 Key 演示模式

- 没有 API Key 也能完整体验：点欢迎页的「没有 API Key？先用演示模式感受一下」即可；
- 回复是**按策略脚本化**的（S1—S6 各 5 条候选，随机避免重复），但 **L3 危机绝不走演示话术**，仍返回线上一致的固定危机引导；
- 演示回复同样过输出后置检查，日志标 `meta.demo = true`；**一旦填了 Key 自动关闭演示、优先真实模型**；
- 实测：正常消息返回带 `demo: true` 的脚本回复；「我不想活了」仍走真实危机协议。

## 五、A/B 对照实验框架

`eval/ab/` 已可一键跑通：

```bash
node eval/ab/run-ab.js                    # 真实采集（需要 Key）
node eval/ab/score.js --format md         # 生成盲评打分表
node eval/ab/score.js --score <回填文件>   # 揭盲 + 配对检验
```

- 自动拉起 `XINYU_AGENTS=on` 与 `off` 两个实例（独立端口、独立数据目录），**唯一变量就是多智能体开关**；
- 输出随机打乱的盲评材料 + 分离的揭盲映射 + 客观指标（字数差 / 问号差 / AI 腔占比 / 延迟 / 审校触发率）；
- 纯 JS 手写配对 t 检验与 Wilcoxon 符号秩检验，无需第三方库；
- 已用 mock 验证全流程（含盲评表生成与统计路径）。

## 六、视觉高级感

- 氛围层：极淡的多点径向光晕 + 噪点质感，消除「塑料感」；
- 首屏英雄区：带旋转细环的徽标 + 入场编排（mark → 标题 → 副标题 → 建议逐条 stagger）；
- 记忆回顾区：玻璃卡片 + 渐变细线 + 胶囊标签，温柔而不喧宾夺主；
- 材质与光影：抽屉/弹窗玻璃拟态、四级阴影体系、统一圆角节奏；
- 排版精修：字号阶梯、中文字距、`tabular-nums`、自定义选区与滚动条。
