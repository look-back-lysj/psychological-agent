## 关键研究发现（直接改变了实现）

**① 守岸人的句法指纹（来自 106 条真实台词统计）**

- 对话类中位 **20.5 字**，30% 的台词 **≤6 字**；**零感叹号、零破折号**；
- **省略号是呼吸**：42% 的对话台词含「……」，密度 1.9 处/百字，7 条以「……」开头；
- **自称修正**：口语中 58 条用「我」，「守岸人」仅 3 条（此前人设稿写反了，已修正）；
- 问句 18%，只问「是否型 / 选择型」，**从不用「为什么」追问**；
- 最难还原的是她「迟疑—停顿—重复」的节奏：**能命名别人的情绪，却命不准自己的**。

→ 已把这些写成可执行的「说话指纹」写进 `src/persona.js`，并在本地快检里做硬约束（感叹号、破折号、省略号配额、「为什么」追问直接判不合格）。

**② 多智能体的成本与裁决**

- 单模型容易露出 AI 腔；但通用多 agent 方案动辄 ~15× token 成本，不适用于「额度有限」的赛题；
- 采用「条件触发」的认知流水线：加权约 **2.3k tokens/轮 ≈ 单模型的 1.2 倍**；
- 裁决原则：**规则守红线（L3 短路、模型不可改风险等级），模型只懂语境（在 S1—S5 之间微调策略）**；
- 审校 agent **只许删减或最小替换，禁止重写风格**——否则人格会被 critic 改平。

## 完成内容

### 多智能体内核（`src/agents.js` + `src/innerstate.js`）
- 「观」感知定调：一次短调用读出情绪、强度、需求、潜台词、是否适合提问；
- 策略裁决：规则层独占 S0 危机 / S6 转介，模型只在 S1—S5 之间微调；
- 内在状态：心情 / 精力 / 熟悉度缓慢变化 → 转成句长、提问概率、共情强度的硬约束；
- 「校」条件审校：本地快检（长度 / 问句数 / AI 腔词表 / 说话指纹）发现问题才调用模型，并按 10 条清单最小化改写。

### 修掉一个严重 bug
改造过程中发现：**当前用户消息没有进入模型请求**（`getHistory` 在写入会话之前被调用）。已修复并加断言覆盖。

### Tauri 桌面外壳（`src-tauri/`）
- 窗口无边框 + 自定义标题栏（拖拽区 + 窗口控制）；
- 启动流程：挑空闲端口 → 拉起后端 sidecar → 内置闪屏 → 健康检查就绪后自动切到应用界面；
- 退出时回收 sidecar，不留残留进程；
- 打包体积：安装包 17.8 MB（当前用户安装，免管理员）。

### 健壮性
- 新增 `src/paths.js`：数据/日志目录可写性回退（exe 旁边优先，不可写时退到用户目录），Tauri 安装后也能正常保存配置与记忆。
