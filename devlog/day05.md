# 开发日志 - 第 5 天

## 目标

按验收清单与实施指南做一次**全面升级**：让使用者「安装 + 填 DeepSeek API Key」就能顺滑使用；
人设换成《鸣潮》守岸人的语调与性格；记忆稳定；交互更像真人。

## 三个关键研究发现（直接影响实现）

1. **DeepSeek 模型已换代**：`deepseek-chat` / `deepseek-reasoner` 已下线，当前推荐 `deepseek-flash`；
2. **思考模式默认开启会吞掉 `temperature`**：必须显式传 `thinking: { type: 'disabled' }`（且仅对 DeepSeek 域名下发），否则温度调参等于白设；
3. **守岸人的角色内核与产品硬边界正面冲突**：她的设定核心是「承诺保守秘密」与「永久守望」，
   而本产品必须「不承诺保密、不诱导依赖」。处理方式是**把守望的方向反转**——
   从「我永远等你」改成「你随时可以来，也可以不来」，并全量禁用游戏专有名词与恋爱向台词。

### 策略与安全
- `src/strategy.js` 重写为 **S0—S6 策略库 + 对话状态机**（情绪温度、同策略最多连续 2 轮、追问 ≤2 次、每 4—5 轮小收束），输出可解释路由 JSON；
- `src/safety.js` 升级为 **L0—L3 分级**：直接危机 / 隐蔽风险 / 退缩告别叠加 / 索药 / 越狱 / 关注信号，就高不就低；L3 走**固定危机话术**（不交给模型）；
- 输出后置检查扩展：诊断结论、危险方法、保密承诺、永久承诺与依赖诱导、亲昵称呼、提示词泄露，判定前先做归一化（堵住空格 / 零宽字符绕过）。

### 长期记忆
- 新增 `src/memory.js`：本地 `data/memory.json`，显式「记住…」立即入库 + 每 3 轮后台批量抽取；
- 召回按「置顶 + 相关度 + 重要性」排序，每类最多 2 条，24 小时内用过的降权避免复读；
- 语义相近但结论相反时旧条目**失效保留**（superseded），删除/清空写入 tombstone 防止被重新抽回；
- 支持查看 / 编辑 / 置顶 / 删除 / 一键清空 / 整体关闭，全部在界面内完成。
